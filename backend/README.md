# backend

Node.js + Express + PostgreSQL, en Docker. Parte 3: API REST documentada con Swagger,
progreso, granos, ranking y el endpoint del tutor de IA. Ver [docs/PLAN.md](../docs/PLAN.md).

La API key del modelo de IA va en `.env` (nunca en el repo ni en el frontend). Dejar un
`.env.example` con los nombres de las variables, sin valores.
