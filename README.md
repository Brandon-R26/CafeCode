# CafeCode

Plataforma web para aprender a programar en Python automatizando un cafetal hondureño.
El estudiante hereda una finca de café y, en lugar de mover a su trabajador con el teclado,
le escribe las instrucciones en código. Cada concepto (ciclos, funciones, clases) se
desbloquea cuando la finca lo vuelve necesario.

Proyecto de **Desarrollo de Aplicaciones de Vanguardia** (CCC413), UNITEC, Q4 2026 — Grupo 1.
